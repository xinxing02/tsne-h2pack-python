# Citing

If tsne-h2pack helps your research, please cite the software and the H2Pack paper.

```bibtex
@software{tsne_h2pack,
  title  = {tsne-h2pack: High-Performance t-SNE with H2Pack Acceleration},
  author = {Xing, Xin},
  year   = {2026},
  url    = {https://github.com/xinxing02/tsne-h2pack-python}
}

@article{huang2020toms,
  title   = {{H2Pack}: High-performance {H}$^2$ Matrix Package for Kernel Matrices Using the Proxy Point Method},
  author  = {Huang, Hua and Xing, Xin and Chow, Edmond},
  journal = {ACM Transactions on Mathematical Software},
  volume  = {47},
  number  = {1},
  pages   = {1--29},
  year    = {2020},
  doi     = {10.1145/3412850}
}
```
