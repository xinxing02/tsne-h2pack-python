API reference¶

tsne_h2pack.TSNE ¶

TSNE(
    n_components: int = 2,
    perplexity: float = 30.0,
    early_exaggeration: float = 12.0,
    learning_rate: Union[float, str] = "auto",
    max_iter: int = 1000,
    n_iter_without_progress: int = 300,
    min_grad_norm: float = 1e-07,
    metric: str = "euclidean",
    init: Union[str, ndarray] = "pca",
    verbose: int = 0,
    random_state: Optional[int] = None,
    method: str = "h2pack",
    n_jobs: Optional[int] = None,
    h2_tol: Optional[float] = None,
    h2_rebuild_freq: Optional[int] = None,
    enable_profiling: bool = False,
    profiling_output_file: Optional[str] = None,
    knn_method: str = "pynndescent",
    knn_params: Optional[dict] = None,
    h2_rebuild_freq_early: Optional[int] = None,
    h2_leaf_size: Optional[int] = None,
)

t-SNE: t-Distributed Stochastic Neighbor Embedding with H2Pack acceleration.

Drop-in replacement for sklearn.manifold.TSNE with identical API.

Parameters:
  • n_components (int, default: 2 ) –

    Dimension of the embedded space.

  • perplexity (float, default: 30.0 ) –

    The perplexity is related to the number of nearest neighbors that is used in other manifold learning algorithms. Larger datasets usually require a larger perplexity. Consider selecting a value between 5 and 50. Different values can result in significantly different results.

  • early_exaggeration (float, default: 12.0 ) –

    Controls how tight natural clusters in the original space are in the embedded space and how much space will be between them.

  • learning_rate (float or auto, default: 'auto' ) –

    The learning rate. 'auto' uses max(n_samples / 12, 200), the rule FIt-SNE and openTSNE use: a fixed rate of a few hundred badly under-converges once n_samples reaches the tens of thousands.

  • max_iter (int, default: 1000 ) –

    Maximum number of iterations for the optimization.

  • n_iter_without_progress (int, default: 300 ) –

    Maximum number of iterations without progress before we abort the optimization.

  • min_grad_norm (float, default: 1e-7 ) –

    If the gradient norm is below this threshold, the optimization will be stopped.

  • metric ((euclidean, precomputed), default: 'euclidean' ) –

    'euclidean': X is a feature array and the k-NN graph is built with knn_method. 'precomputed': X is a sparse (n_samples, n_samples) matrix of k-NN distances (not squared), as returned by sklearn.neighbors.kneighbors_graph(..., mode='distance') or any other k-NN library; every row needs more than perplexity neighbors (3 * perplexity is what the 'euclidean' path uses). The k-NN search is skipped, so several runs, or several libraries, can share one graph.

  • init ((random, pca), default: 'random' ) –

    Initialization of the embedding. 'pca' follows scikit-learn: the PCA projection of X (svd_solver='randomized', seeded with random_state) rescaled so that the first coordinate has standard deviation 1e-4; it usually preserves the global structure better. 'random' draws each coordinate from N(0, 1e-4) in the C extension. PCA needs features, so with metric='precomputed' an init of 'pca' falls back to 'random' with a warning (pass init='random' to silence it). An ndarray is used as the initial embedding as is (no rescaling).

    .. versionchanged:: 3.3.0 The default changed from 'random' to 'pca', as in scikit-learn 1.2.

  • verbose (int, default: 0 ) –

    Verbosity level. If > 0, prints progress information.

  • random_state (int or None, default: None ) –

    Random seed for reproducibility.

  • method (str, default: 'h2pack' ) –

    Method for repulsive force computation: - 'h2pack': Use H2Pack for O(N) computation (default) - 'exact': Use direct O(N²) computation

  • n_jobs (int or None, default: None ) –

    Number of threads for the k-NN search, the optimizer and H2Pack. None means 1 thread; -1 means all cores (joblib convention).

  • h2_tol (float, default: None ) –

    H2Pack low-rank approximation tolerance. Lower values = more accurate but slower. None selects the default for n_components (see H2_DEFAULTS; 1e-2 in 2D, which already reproduces the embedding quality of an FFT (openTSNE) run). Only used when method='h2pack'.

  • h2_rebuild_freq (int, default: None ) –

    The H2 matrix is rebuilt, and the repulsive force recomputed, every this many iterations; in between, the last repulsive force is reused. Lower values = more accurate but slower (in 2D, 2 is slightly better than FIt-SNE's quality, 3 is on par). None selects the default for n_components. Only used when method='h2pack'.

  • h2_rebuild_freq_early (int, default: None ) –

    Rebuild frequency during early exaggeration (after the first 20 iterations), a phase that is insensitive to a delayed repulsive force. Never lower than h2_rebuild_freq. None selects the default for n_components.

  • h2_leaf_size (int, default: None ) –

    Maximum number of points per H2 leaf box. Affects speed and memory only, not accuracy. None selects the default for n_components.

  • enable_profiling (bool, default: False ) –

    Enable detailed profiling of computation time breakdown.

  • profiling_output_file (str or None, default: None ) –

    Path to save profiling CSV data. If None, uses default name.

  • knn_method (str, default: 'pynndescent' ) –

    k-NN method for finding nearest neighbors: - 'pynndescent': PyNNDescent approximate k-NN (default, ~96% recall, auto-tuning) - 'exact': sklearn brute-force exact k-NN - 'balltree': sklearn ball tree exact k-NN - 'faiss': FAISS approximate k-NN (CPU-only, very fast) - 'annoy': Annoy approximate k-NN (memory-efficient)

  • knn_params (dict or None, default: None ) –

    Method-specific parameters for k-NN computation. See _knn_methods.py for details on each method's parameters. Common parameters:

    PyNNDescent (auto-tuning default): - n_trees: Number of RP trees (None=auto, default varies by dataset size) - n_iters: Search iterations (None=auto, default varies by dataset size) - metric: Distance metric (default='euclidean')

    FAISS: - index_type: 'Flat', 'IVFFlat', 'IVFPQ', 'HNSW' (default='IVFFlat') - nlist: Number of clusters for IVF (default=100) - nprobe: Clusters to search (default=10) - use_gpu: Use GPU if available (default=False)

    Annoy: - n_trees: Number of trees (default=50) - search_k: Search depth (default=-1, auto)
Attributes:
  • embedding_ (ndarray of shape (n_samples, n_components)) –

    Stores the embedding vectors.

  • kl_divergence_ (float) –

    Kullback-Leibler divergence after optimization.

  • n_iter_ (int) –

    Number of iterations run.

Examples:

>>> from tsne_h2pack import TSNE
>>> import numpy as np
>>> X = np.random.randn(1000, 50)
>>> tsne = TSNE(n_components=2, perplexity=30, random_state=42)
>>> Y = tsne.fit_transform(X)
>>> print(Y.shape)
(1000, 2)

fit_transform ¶

fit_transform(X: ndarray, y=None) -> np.ndarray

Fit X into an embedded space and return that transformed output.

Parameters:
  • X (ndarray of shape (n_samples, n_features)) –

    Input data.

  • y (Ignored, default: None ) –

    Not used, present for API consistency by sklearn convention.
Returns:
  • X_new( ndarray of shape (n_samples, n_components) ) –

    Embedding of the training data in low-dimensional space.
